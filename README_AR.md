# تطبيق العمران للخطط - نسخة مصححة V2

هذه نسخة Android Native وليست صفحة ويب. تعمل بدون إنترنت وتسمح لك بإدخال الخطة واللاعبين والبدلاء ثم حفظ التصميم كصورة.

## الميزات
- تصميم قريب من الصورة المطلوبة: ملعب طولي، ألوان خضراء، لاعبين بدوائر زرقاء، لوغو العمران، مربع البدلاء، ومفتاح المراكز.
- إدخال أسماء اللاعبين مباشرة من التطبيق.
- الخطة الافتراضية: 3-3-1.
- أسماء افتراضية حسب طلبك:
  - الحارس: ابو الليث
  - الدفاع: حسونة - عبدالله - عبدالخالق
  - أمام المدافعين: جليبيب
  - الوسط المتقدم: سلوم - ابو احمد
  - رأس الحربة: يوسف
  - البديل: مصطفى عثمان
- زر لإظهار/إخفاء الأسهم.
- زر حفظ صورة في المعرض.

## طريقة استخراج APK من GitHub
1. ارفع كل ملفات المشروع إلى المستودع.
2. ادخل تبويب Actions.
3. شغّل Build APK.
4. بعد الانتهاء حمل Artifact باسم: `AlOmranTacticsApp-v2-debug-apk`.
5. داخله ستجد: `app-debug.apk`.

## ملاحظة مهمة
إذا ظهر تحذير أثناء تثبيت APK، اضغط تثبيت على أي حال لأنه Debug APK من مشروعك الشخصي.
